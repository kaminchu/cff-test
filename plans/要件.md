cloudfront functinsのjsコードをローカルでテストするcliツールを作りたい


構成例
```
cff-test
 ├─ CLI parser
 ├─ CloudFront compatibility checker
 ├─ QuickJS runtime
 │    ├─ restricted globals
 │    ├─ fixed Date
 │    ├─ Buffer
 │    ├─ crypto
 │    └─ CloudFront-specific modules
 └─ JSON assertion
```

コマンド例

```
cff-test src/function.js \
  -i event.json \
  -o expected.json
```
```
cff-test run src/function.js -i event.json
cff-test check src/function.js
cff-test test src/function.js -i event.json -o expected.json
```


```
                    ┌──────────────┐
function.js ───────▶│ static check │
                    │ CFF allowlist│

                    │   QuickJS    │
                    │ restricted   │
                    │ environment  │
                    └──────┬───────┘
                           │
                           ▼
                      handler(event)
```
